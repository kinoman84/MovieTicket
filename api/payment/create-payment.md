# Инициация оплаты заказа

## Описание

Метод вызывается покупателем после резервирования мест. Он создаёт платёж у
единственного внешнего платёжного провайдера, сохраняет его идентификатор и
возвращает ссылку на оплату.

## URL

`POST /v1/orders/{orderId}/payment`

## Логика обработки запроса

1. Найти запись в таблице [orders](../../db/data-model.dbml), для которой
   `orders.id` = `orderId`.
   * Если заказ не найден, прекратить обработку и вернуть `404 Not Found`.
2. Проверить готовность заказа к оплате:
   * `orders.status` = `pending_payment`;
   * для заказа существуют билеты в [tickets](../../db/data-model.dbml) со
     статусом `held`;
   * для заказа отсутствует запись в [payments](../../db/data-model.dbml).
   * Если хотя бы одно условие не выполнено, не создавать платёж и вернуть
     `409 Conflict`.
3. Отправить запрос `POST /payments` в
   [Payment provider API](../../external-systems/payment-provider/openapi.yaml),
   передав итоговую сумму `orders.total_amount` и URL endpoint обработки callback.
   * Сохранить полученные от провайдера идентификатор платежа и платёжную ссылку.
4. Создать запись в [payments](../../db/data-model.dbml), связав её с заказом, сохранив идентификатор и
   ссылку провайдера, а также статус `pending`.
5. Вернуть сведения об инициированном платеже в соответствии с
   [контрактом](../openapi.yaml).

### Маппинг запроса на создание платежа

| Целевое поле | Источник данных | Правило заполнения |
|:-------------|:----------------|:-------------------|
| `paymentRequest.orderId` | `orders.id` | Передать идентификатор найденного заказа без преобразования. |
| `paymentRequest.amount` | `orders.total_amount` | Передать итоговую сумму заказа без преобразования. |
| `paymentRequest.callbackUrl` | URL `POST /v1/payment-callbacks` КиноБилета | Передать абсолютный URL endpoint обработки итогового статуса платежа. |

### Маппинг ответа провайдера в платёж

| Целевое поле | Источник данных | Правило заполнения |
|:-------------|:----------------|:-------------------|
| `payments.order_id` | `orders.id` | Связать создаваемый платёж с найденным заказом. |
| `payments.provider_payment_id` | `paymentResponse.providerPaymentId` | Сохранить идентификатор, возвращённый провайдером. |
| `payments.payment_url` | `paymentResponse.paymentUrl` | Сохранить ссылку для перенаправления покупателя на оплату. |
| `payments.status` | Константа `pending` | Присвоить при создании платежа до получения callback. |
