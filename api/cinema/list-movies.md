# Получение списка фильмов

## Описание

Метод вызывается покупателем при выборе фильма. Он возвращает каталог фильмов,
которые могут быть показаны в кинотеатрах, и не изменяет данные.

## URL

`GET /v1/movies`

## Логика обработки запроса

1. Получить все записи из таблицы [movies](../../db/data-model.dbml).
2. Сформировать список фильмов из найденных записей.
3. Вернуть список в соответствии с [контрактом](../openapi.yaml).

## Связанные документы

- [OpenAPI](../openapi.yaml) — HTTP-контракт получения списка фильмов.
- [Data model](../../db/data-model.dbml) — таблица `movies`.
