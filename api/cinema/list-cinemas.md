# Получение списка кинотеатров

## Описание

Метод вызывается покупателем при ознакомлении с доступными кинотеатрами. Он
возвращает актуальный локальный справочник кинотеатров и не изменяет данные.

## URL

`GET /v1/cinemas`

## Логика обработки запроса

1. Получить все записи из таблицы [cinemas](../../db/data-model.dbml).
2. Сформировать список кинотеатров из найденных записей.
3. Вернуть список в соответствии с [контрактом](../openapi.yaml).

## Связанные документы

- [OpenAPI](../openapi.yaml) — HTTP-контракт получения списка кинотеатров.
- [Data model](../../db/data-model.dbml) — таблица `cinemas`.
