# Получение заказа

## Описание

Метод вызывается покупателем для проверки состояния оформленного заказа и его
билетов. Он читает данные заказа и не изменяет их.

## URL

`GET /v1/orders/{orderId}`

## Логика обработки запроса

1. Найти запись в таблице [orders](../../db/data-model.dbml), для которой
   `orders.id` = `orderId`.
   * Если заказ не найден, прекратить обработку и вернуть `404 Not Found`.
2. Получить записи из таблицы [tickets](../../db/data-model.dbml), для которых
   `tickets.order_id` равен
   идентификатору найденного заказа.
3. Сформировать текущее представление заказа и связанных билетов.
4. Вернуть заказ в соответствии с [контрактом](../openapi.yaml).

## Связанные документы

- [OpenAPI](../openapi.yaml) — HTTP-контракт получения заказа.
- [Data model](../../db/data-model.dbml) — таблицы `orders` и `tickets`.
