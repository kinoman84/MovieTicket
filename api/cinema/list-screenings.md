# Получение списка сеансов

## Описание

Метод вызывается покупателем после выбора кинотеатра или фильма либо без фильтра,
чтобы увидеть доступные сеансы. Он читает локальное расписание и не изменяет
данные.

## URL

`GET /v1/screenings`

## Логика обработки запроса

1. Получить записи из таблицы [screenings](../../db/data-model.dbml), связав
   каждую из них с таблицами `halls` и `movies`. Применить условия отбора:
   * `halls.cinema_id` = `cinemaId`, если `cinemaId` передан; иначе не
     ограничивать сеансы по кинотеатру;
   * `screenings.movie_id` = `movieId`, если `movieId` передан; иначе не
     ограничивать сеансы по фильму.
2. Сформировать список всех найденных сеансов.
3. Вернуть список в соответствии с [контрактом](../openapi.yaml).

## Связанные документы

- [OpenAPI](../openapi.yaml) — HTTP-контракт получения списка сеансов.
- [Data model](../../db/data-model.dbml) — таблицы `screenings`, `halls` и
  `movies`.
